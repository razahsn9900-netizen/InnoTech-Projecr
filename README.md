Smartcity 360 — Student Project
Category: Smart Solutions, Smarter Society
Domain: Affordable Technology for Rural Development
What is this?
Smartcity 360 is a beginner-friendly website prototype for reporting and tracking common community problems such as potholes, garbage overflow, water leakage, and broken streetlights.
Features
Responsive dashboard with category totals
Issue-reporting form
Unique complaint ID for every new report
Search by complaint ID, category, location, description, or status
Demo admin control to update complaint status
Saves reports in the browser using localStorage
How to run it
Download and extract Smartcity360_Project.zip.
Open the Smartcity360_Project folder in VS Code.
Open index.html in a browser, or install the Live Server extension in VS Code.
If using Live Server, right-click index.html and choose Open with Live Server.
No installation or API key is required.
Important limitation
This is a front-end demonstration. Data is stored only in the current browser on the current device; it is not sent to a real municipal authority. The map, live traffic, GPS, image upload, user accounts, and real multi-user database are not included in this beginner version.
Suggested technology explanation
HTML: page structure and forms
CSS: responsive layout and visual design
JavaScript: form handling, search, status changes, counters
localStorage: saves demo complaints in the same browser
